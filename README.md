## What This Repository Is

This repository contains the complete literature base for the **Brandon (2026)** PhD dissertation:

> *"Quality at Entry as a Predictor of Development Project Outcomes: A Multi-Institutional Empirical Analysis Across 31,737 Projects"*

The systematic literature review spans **26 streams** covering development project evaluation, MDB econometrics, causal identification, institutional architecture, SIDS finance, climate adaptation finance, and non-linear collapse theory. The empirical core finding is an odds ratio of **OR = 27.8** [95% CI: 23.7–32.6] for Quality at Entry (QE) predicting Satisfactory project outcomes across n = 31,737 World Bank and ADB projects (AUC = 0.908).

The repository holds **~300 files**: primary literature PDFs, stream synthesis documents, coding protocols, and supporting materials.

## How to Use This Repository

1. **Finding a paper:** Search by filename or use the stream table above.
2. **Stream coding:** Each stream has a companion `.docx` synthesis file. Read the `.docx` before diving into PDFs.
3. **Gap analysis:** See the Gap Audit section above. The three primary gaps are S21 (adaptation finance), S09 (halo bias measurement), and S14 (QE causal identification).
4. **New papers:** Files not yet assigned N-numbers are listed in the New Papers table. Assign before submission.
